Manajemen Item Rental

Kelola data inventaris, harga sewa, stok, dan status ketersediaan unit peralatan produksi Karsa Rental yang terhubung ke database **Supabase**.

Jalankan SQL ini di SQL Editor Supabase Anda jika tabel belum dibuat: 
CREATE TABLE IF NOT EXISTS public.rental_items (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nama TEXT NOT NULL,
    kategori TEXT NOT NULL DEFAULT 'Kamera',
    harga_sewa NUMERIC NOT NULL DEFAULT 0,
    stok INT NOT NULL DEFAULT 1,
    status TEXT NOT NULL DEFAULT 'Tersedia',
    deskripsi TEXT,
    gambar_url TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

ALTER TABLE public.rental_items ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Public full access to rental_items" ON public.rental_items FOR ALL USING (true) WITH CHECK (true);
⚠️
Kredensial Supabase Belum Dikonfigurasi Silakan klik tombol **Set Supabase** di kanan atas untuk memasukkan URL & Anon Key proyek Supabase Anda.
